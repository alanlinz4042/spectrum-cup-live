# Spectrum Cup Live

Live scores for **Swings for the Spectrum Cup 2026**, a two-team golf match between **Pin Seekers** and
**Iron Legends**, played October 22–24, 2026 in Ridgedale, Missouri.

**Follow along: [alanlinz4042.github.io/spectrum-cup-live](https://alanlinz4042.github.io/spectrum-cup-live/)**

## What you'll see

- **Cup**: the overall team standings and a points tally for each player. Each match is worth up to 3 points:
  1 for the front half, 1 for the back half and 1 overall. Ties split the point, and 72 points are up for grabs in total.
- **Live**: every match's score as it comes in from the course, with how many holes have been played, or the
  tee time if the match hasn't started yet.

Scores refresh automatically about once a minute while the page is open. There's nothing to install or sign in to,
and the page works on phones. To open straight on the Live tab, add `#live` to the address:
[alanlinz4042.github.io/spectrum-cup-live/#live](https://alanlinz4042.github.io/spectrum-cup-live/#live).

## What stays private

This is a read-only, spectator view. Players enter scores in a separate, private scorecard, and only the results
are published here. Contact details, handicaps and anything involving money are never included.
